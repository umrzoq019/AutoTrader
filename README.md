# AutoTrader V9 — Android

Android 8.0+ market-monitoring application for public crypto price feeds, multi-venue market scanning, and experimental online forecasts. It is **not** verified profitable and **does not** place real-money trades.

## Build APK

Use the **Build Android APK** workflow in **Actions**. It reconstructs and compiles the Android source and uploads `app-debug.apk` as a workflow artifact. You can also inspect the application source in the repository after extraction.

Do not commit exchange API credentials, private keys, bank details, or signing secrets.
